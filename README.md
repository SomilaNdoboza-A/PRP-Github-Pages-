# Somila Ndoboza — Software Engineering Portfolio

A responsive static portfolio website designed for GitHub Pages.

## Files
- `index.html` — main portfolio page
- `assets/styles.css` — responsive visual design
- `assets/script.js` — mobile navigation and current year
- `evidence/entrepreneurial-wil/` — five Agile artefacts and a reflection summary

## Publish with GitHub Pages
1. Create a GitHub repository named `SomilaNdoboza-A.github.io` (or use an existing portfolio repository).
2. Upload the contents of this folder to the repository root. `index.html` must be in the root.
3. In GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then save.
6. Wait for GitHub Pages to publish the site. Your URL will be shown in the Pages settings.
